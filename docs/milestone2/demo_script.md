# 5-Minute Milestone 2 Demo

1. Explain: Milestone 1 answers "What happened?"; Milestone 2 answers "Is it suspicious, and how suspicious?"
2. Show the architecture: processed events → preprocessing → Isolation Forest → rules → confidence → MongoDB → FastAPI → React.
3. Point out the KPI cards.
4. Open a suspicious event such as EVT002.
5. Explain the confidence score and clarify it is not a calibrated attack probability.
6. Show the reasons: failed-login threshold, after-hours activity and impossible travel.
7. Show charts for anomaly distribution and threat types.
8. Use live prediction with a brute-force example.
9. Explain that predictions are stored in `threat_predictions`.
10. Mention that deep learning, LLMs and Milestone 3 risk prioritization are intentionally out of scope.
